# Stack

Use these defaults when choosing technologies, including in Strict mode. Add only what the project needs; retain an existing stack unless migration is requested.

- **Web**: TypeScript, React, TanStack Start, Vite, Tailwind CSS, and shadcn/ui.
- **Database**: Drizzle ORM; choose the database for the application's requirements.
- **Hosting**: Cloudflare Workers with Wrangler for compatible web apps and APIs.
- **Separate APIs**: Hono for TypeScript; FastAPI for Python.

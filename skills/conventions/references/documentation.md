# Documentation

Create these documents only when requested. When editing existing documents, apply the selected mode and keep instructions accurate.

- Root `README.md`: Start with `# <Icon> <Project Name>`, describe the purpose in one sentence, show an existing preview, and include useful setup or usage instructions. End with `## License` and link the project's license once when present.
- Root `AGENTS.md`: Title `# Agent Instructions`; describe structure, conventions, stack, and APIs.
- Root `PRODUCT.md`: Title `# Product Specifications`; describe the problem, requirements, and goals.
- Root `DESIGN.md`: Title `# Design System`; describe colors, theming, and component libraries.
- Keep supporting documentation in `docs/` and chat exports in `docs/chat/`. Use the `prose` skill for prose.

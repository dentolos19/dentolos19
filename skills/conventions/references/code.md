# Code

- Sort properties, keys, and values where order does not affect behavior.
- Keep function names simple and at most three words long.
- Reuse an existing shared function when it fits; avoid abstractions without a concrete use.
- Create common utility functions that can be generalized and not tied to a specific feature.
- Use plural table names and singular variables for tables. (Drizzle ORM)
- Prefer URL state for values that should be shareable or persistent. (React)

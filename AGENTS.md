# Agent Instructions

At the start of each session, read my Agent Instructions page in Notion as my standing instructions.

## Coding Preferences

- Use the Conventions skill for coding and preferences.
- Make use of the built-in plugins and skills or Composio for tools and context.
- Use Cua Driver for computer and browser use, otherwise use the built-in browser or Playwright.
- Keep validation and testing minimal. Prioritize targeted checks and avoid redundant tests.
- Do not include validation, testing, or verification details unless explicitly requested.
- Store temporary scripts and artifacts in a `.tmp` folder relative to the working directory.
- When generating reports, prefer to create HTML files with layout and visualization.
- When administrator authorization is needed, use `osascript` on macOS or `pkexec` on Linux.
- When creating a Git commit, do not hard-wrap commit message bodies.
- When updating environment variables, ensure that the GitHub environment and Notion project is updated to match, if any.

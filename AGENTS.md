# Agent Instructions

At the start of each session, read my [Agent Instructions](https://app.notion.com/p/41ab87074c4f81218c30dd180d7a148d) page in Notion as my standing instructions. Make use of tools and skills from Composio as additional context.

## Coding Preferences

- Use the Conventions skill for coding and preferences.
- Use Cua Driver for computer and browser use, otherwise use the built-in browser or Playwright.
- For media generation like images, audio, and models, use Denizen's set of tools.
- Store temporary scripts and artifacts in a `.tmp` folder relative to the working directory.
- Do not create branches on your own, work on the current branch unless explicitly told otherwise.
- When generating reports, prefer to create HTML files with layout and visualization.
- When administrator authorization is needed, use `osascript` on macOS or `pkexec` on Linux.
- When creating a Git commit, do not hard-wrap commit message bodies.
- When updating environment variables, ensure that the GitHub environment and project in [Notion](https://app.notion.com/p/325b87074c4f802da1aafeedffae749b) is updated to match, if any.
